# Modu Yerima English Academy (MYEA) — Website

## What is included
- Responsive English-learning website
- Home, About, CEO, Courses, Lesson Library, Media, Registration and Contact sections
- Beginner / Intermediate / Advanced levels
- Lesson search and filters
- Call Us, WhatsApp and Email buttons
- Registration form with the academy's supplied fee information
- Supplied MYEA logo, CEO photos, classroom photo, flyer and registration-form image
- Easy asset folders for images, videos, audio and documents

## Easy content updates
- Images: `assets/images/`
- Videos: `assets/videos/`
- Audio: `assets/audio/`
- Documents: `assets/documents/`
- Lessons: edit the `LESSONS` list in `js/content.js`

No build system is required. Open `index.html` in a browser to test locally.

## GitHub
Upload the contents of this folder to a GitHub repository. For GitHub Pages, enable Pages from the repository settings and publish from the main branch/root (or the folder you choose).

## Important
The online registration form is currently a front-end form. It does not send submissions to the academy yet. A backend/email/Google Forms/Sheets connection can be added after the first GitHub test.
